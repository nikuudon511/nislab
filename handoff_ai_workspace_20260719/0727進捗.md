## 結果の解釈

### 1. V2N2V経路を使うならRMRがほぼ必須

V2N2V onlyではMEC update failure rateが100%、MEC AoI violation >200msが99.9%となり、MEC経由更新がほぼ有効認識に使えていない。
Hybrid baselineでもMEC update failure rateは79.5%、MEC AoI violation >200msは78.1%であり、V2N2V経路は強いAoI制約を受けている。

一方、Hybrid+RMRではMEC update failure rateが14.4%、MEC AoI violation >200msが22.3%まで低下し、ORRは98.6%まで改善した。
したがって、現条件ではV2N2V経路はRMRにより初めて有効な補完経路として機能したと説明できる。

### 2. Hybrid baselineがV2VとV2N2Vの単純和にならない理由

ORRは同じ物体を複数経路で受信しても1回の認識として数えるため、V2V ORRとV2N2V ORRは足し算できない。
また、両経路の認識対象には重複があり、V2N2V経路ではAoI制約により多くの更新が無効化される。
そのため、Hybrid baselineのORRはV2V単体とV2N2V単体の単純和にはならない。

### 3. 改善要因は平均CBR低下ではなくMEC側の鮮度改善

平均CBRはHybrid baselineとHybrid+RMRでほぼ同じである。

| 指標 | Hybrid baseline | Hybrid + RMR |
|---|---:|---:|
| Channel busy ratio [%] | 80.2389 | 80.2023 |
| MEC DL busy p90 [%] | 100.0 | 84.9 |
| MEC DL busy p99 [%] | 100.0 | 91.2 |
| MEC AoI p99 [ms] | 25579 | 249 |
| MEC AoI >200ms [%] | 78.1 | 22.3 |
| NR CPM payload total [MB] | 12.92 | 4.47 |

つまりRMRは平均CBRを大きく下げたのではなく、V2N2V経路に流れるCPM payloadを削減し、MEC DL busyとAoIを改善した。
このため、MEC経由の有効更新成功率が上がり、ORRが改善したと解釈できる。

### 4. V2V radio lossが50%台に残ることの解釈

Hybrid+RMRでもV2V radio loss rateは55.7%であり、Sidelink単体では依然として損失が大きい。
これは山崎氏の研究でパケットロス率が50%台だった傾向と整合的に見える。

ただし、今回のORRは物体認識単位であり、パケット単位の損失率とは直接一致しない。
V2Vで失われた情報をV2N2V経路が補完することで、V2V radio lossが50%台でもORR 98.6%を達成できたと説明する。

## 懸念点: V2V単体+RMRとの比較が必要

V2V only + RMRの100秒結果により、前回教授に指摘された「V2N2Vを使わず、V2V単体にRMRを入れればよいのでは」という疑問には一定程度答えられるようになった。
今回の条件では、V2V単体にRMRを入れてもORRは改善せず、V2V onlyの61.3%からV2V only + RMRの54.8%へ低下した。

ただし、山崎氏の研究でRMRがV2Vに対して使われていたことを踏まえると、本研究では以下の比較として整理する。

| 比較 | 意味 |
|---|---|
| V2V only | 現在のSidelink単体基準 |
| V2V only + RMR | 山崎氏研究に近い基準。必須比較 |
| Hybrid baseline | V2N2V追加のみの効果 |
| Hybrid + RMR | 本研究の主張対象 |

この比較から、現時点では次のように説明できる。

- V2V+RMRではpacket/radio lossは下がるが、認識に必要な冗長性も削り、ORRが低下する。
- Hybrid+RMRではV2N2V経路のAoI悪化をRMRが緩和し、V2Vで不足した情報をMEC経路が補完できる。
- したがって、RMRの効果はV2V単体よりも、V2N2Vを含むHybridで顕著に現れる。

### V2V+RMRの100秒結果

`results/bg500_v2v_only_rmr_fixed_seed30_100s/no-control/summary.csv` の100秒結果では、V2V+RMRはRMRなしV2VよりORRが低い。

| 指標 | V2V no RMR | V2V + RMR |
|---|---:|---:|
| ORR [%] | 61.3192 | 54.8371 |
| High priority ORR [%] | 62.3321 | 54.3017 |
| Low priority ORR [%] | 59.5805 | 54.9982 |

| packet/radio loss [%] | 63.8187 | 55.7377 |
| Receiver RL mean | - | 0.495277 |
| Receiver RV mean | - | 0.093639 |

RMRによりpacket/radio lossは約8.1ポイント下がったが、ORRは約6.5ポイント低下した。
したがって、V2V単体ではRMRによる削減が認識機会の減少として働きやすい。

### RMRがV2V単体よりV2N2V/Hybridで効きやすい理由

現時点ではV2N2V単体+RMRを直接評価していないため断定は避ける。
ただし、これまでの結果からは、RMRはV2V単体よりもV2N2Vを含むHybridで改善効果が大きい傾向がある。

理由は以下である。

1. V2V単体では、CPMから物体情報を削除すると、その情報の受信機会が直接減る。
   V2Vでは無線ロスが50%以上残るため、本来ロス耐性として必要な冗長情報まで削るとORRが低下しやすい。

2. V2N2V/MEC経路では、主なボトルネックが無線ロスではなくMEC下りの混雑、キュー滞留、AoI悪化である。
   Hybrid baselineではMEC update failure rateが79.5%、MEC AoI violation >200msが78.1%、MEC AoI p99が25579msであり、情報が古すぎて有効認識に使えていない。

3. RMRによりMEC経路のCPM payloadが削減されると、MEC DL busyとAoIが改善する。
   Hybrid+RMRではMEC update failure rateが14.4%、MEC AoI violation >200msが22.3%、MEC AoI p99が249msまで改善した。

4. MEC経路では多数車両から情報が集約されるため、同一物体に対する冗長情報が増えやすい。
   そのため、RMRで削除しても認識に必要な情報が他車両・他時刻・他経路から補完されやすい。

5. Hybridでは、V2Vが直接・低遅延の認識を担い、V2N2VがV2Vで落ちた情報や範囲外情報を補完する。
   RMRはこのV2N2V補完経路をAoI制約内で機能させる役割を持つ。

進捗報告での表現案:

> V2V単体ではRMRによる削除が受信機会の減少に直結しやすく、無線ロスに対する冗長性を削ってしまう可能性がある。一方、V2N2V経路ではMEC側に情報が集約されるため冗長情報が多く、主なボトルネックはMEC下りの混雑とAoI悪化である。そのため、RMRはV2N2V経路では不要・重複情報を削減してAoIを改善し、有効更新成功率を高める方向に働く。結果として、RMRの改善効果はV2V単体よりV2N2Vを含むHybridで顕著に現れた可能性がある。

今後の確認事項:

- V2N2V only + RMRを追加評価し、V2N2V経路単体でもRMRがAoI改善に効くかを確認する。
- 経路別RMRを導入し、V2V側は冗長性保護、V2N2V側はAoI改善を目的とする制御に分離する。

## Delooz RL/RV診断の結果

| 指標 | Hybrid baseline | Hybrid + RMR |
|---|---:|---:|
| Receiver RL mean | 1.3086 | 0.4953 |
| Receiver RL median | 0.2692 | 0.0658 |
| Receiver RL >= 1 [%] | 24.8 | 10.7 |
| Receiver RL >= 2 [%] | 15.9 | 4.2 |
| Delooz RV mean | 0.2302 | 0.0936 |

Hybrid+RMRはORRを大幅に改善したが、受信側の冗長性は低下している。
これはRMRが不要情報を削減してAoIを改善した一方で、パケットロス耐性としての冗長性を削っていることを示す。

今後は、単に削除数を増やすのではなく、RL/RVを見ながら「削ってよい情報」と「残すべき冗長情報」を分けるRL-aware RMRが有望である。

## スライドでの注意点

- 平均CBRはHybrid baselineとHybrid+RMRでほぼ同じなので、RMRの改善要因として平均CBR低下を主張しない。
