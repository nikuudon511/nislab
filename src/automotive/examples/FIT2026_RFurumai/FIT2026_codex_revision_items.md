# Codex向け修正事項：FIT2026_RFurumai0629.pdf

対象：修正後PDF `FIT2026_RFurumai0629.pdf`  
目的：査読耐性をさらに高めるため，LaTeX原稿に以下の軽微修正を反映する。

---

## 修正方針

修正後原稿は前回版より大きく改善されている。特に，式(1)の説明，式(3)の場合分け，MEC/V2N2V経路の前提条件の明記は良い。  
残る修正は主に以下の4点。

1. 断定的な安全表現を弱める
2. 予測CBRの役割を「V2N2V転送確率制御」として明示する
3. 図2のCBRが百分率表示であることを明記する
4. 評価条件にV2V通信方式を追加する

---

## 優先度A：必ず修正する

### A-1. 「事故に直結する」を弱める

#### 対象箇所
3.3「物標重要度に基づく帯域適応型経路制御方式」

#### 現在の文
```tex
混雑環境下における高重要度情報の消失は事故に直結するため，V2V と V2N2V の
双方の通信経路を用いて二重送信を行い，到達信頼性を向上させる．
```

#### 修正案
```tex
混雑環境下における高重要度情報の未達は安全性低下に直結する可能性があるため，
V2V と V2N2V の双方の通信経路を用いて二重送信を行い，到達信頼性を向上させる．
```

#### 意図
「事故に直結する」は査読上やや断定が強い。  
「安全性低下に直結する可能性がある」とすることで，主張を保ちつつ学術文として自然にする。

---

### A-2. 予測CBRの役割を明示する

#### 対象箇所
4.2「評価結果および考察」の末尾付近

#### 現在の文
```tex
また，流入車両数の変化が比較的連続的であったため，予測 CBR 単体の ORR 改
善効果は限定的であり，合流部や多車線流入など CBR
が急変する環境での評価は今後の課題である．
```

#### 修正案
```tex
また，流入車両数の変化が比較的連続的であったため，予測 CBR に基づく RMR 単独では
反応型 RMR との差は限定的であった．一方，予測 CBR を V2N2V 転送確率の制御に用いることで，
将来の V2V 混雑を考慮した補完送信が可能となった．
合流部や多車線流入など CBR が急変する環境での評価は今後の課題である．
```

#### 紙面が足りない場合の短縮案
```tex
また，本評価環境では予測 CBR に基づく RMR 単独では反応型 RMR との差は限定的であったが，
予測 CBR を V2N2V 転送確率制御に用いることで，将来の V2V 混雑を考慮した補完送信が可能となった．
CBR が急変する環境での評価は今後の課題である．
```

#### 意図
現状では「予測CBR単体の効果は限定的」という印象が残る。  
タイトルに「交通流予測に基づく」とあるため，予測CBRの主な貢献が「RMR単独の改善」ではなく「V2N2V補完送信の事前制御」にあることを明示する。

## 優先度B：可能なら修正する

### B-1. 図2の平均CBRが百分率表示であることを明記する

#### 対象箇所
図2のキャプション，または図2凡例

#### 現在のキャプション
```tex
図 2 各方式における周辺物標認識率（ORR）と平均
CBR の比較結果
```

#### 修正案
```tex
図 2 各方式における周辺物標認識率（ORR）と平均
CBR（百分率表示）の比較結果
```

#### 別案
```tex
図 2 各方式における周辺物標認識率（ORR）と平均
CBR（CBR $\times$ 100）の比較結果
```

#### 意図
本文中のCBRは通常0〜1の比率として扱われるが，図2では赤線が%軸上に描かれている。  
百分率表示であることを明記すると誤読を避けられる。

---

### B-2. 表1または本文にV2V通信方式を追加する

#### 対象箇所
表1「主な評価条件」または4.1「評価環境」

#### 表1に入れる場合の例
```tex
V2V 通信方式 & IEEE 802.11p \\
```

#### 本文に入れる場合の例
```tex
V2V 通信には IEEE 802.11p を想定した．
```

#### 注意
実際に使用している通信方式に合わせて記述すること。  
IEEE 802.11pでない場合は，ns-3設定に合わせて `ITS-G5`，`LTE-V2X`，`NR-V2X` など正しい名称に置き換える。

#### 意図
CBRやパケット衝突を扱う評価であるため，通信方式が不明だと再現性の観点で弱く見える。  
紙面制約がある場合でも，通信方式だけは明記した方がよい。
