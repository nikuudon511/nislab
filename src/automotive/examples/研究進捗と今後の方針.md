# 研究進捗と今後の方針

## 1. 研究目的

交通流に基づく予測CBRを用いて通信混雑を事前に検知し、V2VとV2N2Vを適応的に利用することで、高負荷環境における環境認識性能を維持しながらV2N通信量を抑制する。

予測とV2N2Vの役割は異なる。

- 予測CBR: いつ、どの区間で制御を開始するかを決める。
- V2N2V: V2Vで欠落する認識情報を補完する。
- 適応制御: 高重要度ORRなどの制約を満たす範囲でV2N使用量を抑える。

## 2. 現在の実装

- 3 km双方向直線道路、6車線、RSU 6基。
- CAVと非CAVが混在し、非CAVもORRの認識対象に含む。
- センサ範囲100 m、ORR評価範囲200 m。
- 高重要度は距離50 m以内、または接近速度3 m/s以上かつTTC 5秒以下。
- 高重要度AoI閾値0.2秒、低重要度AoI閾値0.5秒。
- RSU間は高速・高信頼な有線バックホールによる情報共有を抽象化している。
- 車両は進行方向にある次のRSUから、I2V範囲内でのみ予測CBRを受け取る。
- RSU別の実測CBR、予測CBR、ピーク先行時間、I2V対象台数をCSV出力する。
- 道路上を移動する高負荷BG区間を実装済み。

比較手法:

1. `no-control`
2. `predictive-rmr-v2v`
3. `v2n2v-high-priority-only`
4. `v2n2v-adaptive-probability`

## 3. 現時点の結果

120秒実験の72秒時点:

- 実測CBR平均: 0.627
- 予測CBR平均: 0.701
- 予測バイアス: +0.074
- RSU別のCBR 0.6検知先行時間: 0～13秒
- 平均先行時間: 約7.2秒
- `predictive-rmr-v2v`平均ORR: 53.76%
- `adaptive`平均ORR: 89.75%
- `adaptive`平均MEC経路数: 75.3台

確認できた事項:

- RSU別予測と地域限定I2Vは動作している。
- 一部RSUでは実測CBRより数秒早く混雑を検知できた。
- V2N2V補完によって高負荷時のORRは大きく改善した。

未解決事項:

- 基礎負荷が高く、移動高負荷区間の地域差が埋もれている。
- 多くの車両がMECへ移行し、負荷通過後のV2V復帰を確認できていない。
- 予測あり・なしadaptiveの最終ORR差は小さい可能性がある。
- 予測の早期切替が増加させるV2N量と、その利益を比較する必要がある。

## 4. 今後の評価方針

評価目的の異なる2つのシナリオに分ける。道路、車両、通信条件は可能な限り共通化する。

### 4.1 V2N2V送信方針の評価

目的:

- 高負荷時にORRとV2N通信量のバランスがよい方式を明らかにする。

比較:

- no-control
- predictive-RMR
- high-priority-only
- adaptive-probability

主要指標:

- 全体、高重要度、低重要度ORR
- AoI違反率、未受信率
- MEC uplink bytes、forwarded bytes、`mec_tx`
- ORR改善1ポイント当たりのV2N量

期待する解釈:

- all-object相当はORRが高いが通信量も大きい。
- high-onlyは通信量を抑えるが低重要度ORRが低下する。
- adaptiveは両者のトレードオフを改善する。

### 4.2 予測CBRの有効性評価

目的:

- 実測CBRによる反応型制御より、下流混雑を利用した制御が早く適切な方式へ遷移できるか確認する。

評価環境:

- RSU区間ごとに再現可能な負荷の山谷を設定する。
- 例: CBR 0.4、0.6、0.8、0.9、0.6、0.4。
- 固定CBRは予測器の精度評価ではなく、制御機構の再現可能な基礎評価として扱う。

比較:

- 実測CBRによるadaptive制御
- 下流CBRの先行情報を用いるadaptive制御

主要指標:

- 閾値検知と経路切替の先行時間
- 混雑区間進入直後のORRとAoI違反率
- 負荷通過後の復帰時間
- 過剰MEC利用時間と追加V2N量

## 5. オフライン最適方式選択

負荷ごとに、認識制約を満たす最小V2N通信量の手法を選択する。

目的:

```text
minimize: V2N通信量
subject to:
  高重要度ORR >= 目標値
  全体ORR >= 目標値
```

低負荷ではV2V単体、中負荷ではpredictive-RMR、高負荷ではadaptiveなどが選択される可能性がある。ただし結論は実験結果から決定し、事前に固定しない。

## 6. 論文のストーリー

主張:

> 交通流予測に基づく事前経路制御とV2N2V補完を組み合わせ、高負荷時の環境認識性能と通信効率の両立を図る。

評価を分ける理由:

- V2N2V評価では、補完方針による認識性能と通信量を測定する。
- 予測評価では、負荷遷移を制御して事前切替の効果を測定する。
- 各構成要素を独立して評価することで交絡要因を減らす。

想定質問への回答:

- 予測だけでは高負荷時のV2V欠落を回復できない。
- V2N2Vを常時使うとV2N通信量が増える。
- 予測は必要な区間と時間を判断し、V2N2Vは欠落を補完する。
- 2つの評価環境は同じ提案方式の異なる構成要素を検証するために使用する。

## 7. 成功・撤退基準

予測制御の有効性:

- 混雑検知または切替が実測CBR制御より早い。
- 進入直後のORR、AoI違反、欠落時間のいずれかが改善する。
- 追加V2N量が改善効果に対して過大でない。

予測効果が限定的な場合:

- 定常高負荷では追加効果が小さいことを結果として示す。
- 有効となる負荷遷移条件を整理する。
- V2N2V送信方針と通信効率を主要成果とする。

実装方針:

- 新しいオンライン最適化やDENM相当機能は追加しない。
- 現在の120秒実験を完了させる。
- 移動BGの調整は必要最小限に留める。
- その後、固定負荷区間による予測比較と負荷別4手法比較を優先する。
